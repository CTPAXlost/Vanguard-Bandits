Vanguard Bandits Remaster 1.8.1 — отчёт проверки

Причина исправления:
GitHub Actions останавливался на runtime smoke-тесте главы V. Миссия передавала идентификаторы «bastion» и «andrew» вместо существующих balance-профилей. Из-за пустого словаря характеристик не создавалась HP-панель, после чего создание группы возвращало null. Риг также обращался к global_transform до добавления в SceneTree.

Исправлено:
- Bastion использует профиль bastion_alba;
- Andrew использует профиль andrew_vedocorban;
- добавлены полноценные профили Sadira/Sylpheed, Franco/Korbelan и Halak/Korbelan;
- добавлены совместимые псевдонимы balance-профилей и безопасные резервные характеристики;
- HP-панели создаются безопасно;
- добавлена null-защита создания героев, противников и нейтралов;
- Skeleton3D не обращается к global_position до входа в SceneTree.

Проверки:
- Python unittest: 115 тестов успешно;
- JSON: 29 файлов успешно разобраны;
- буквальные ссылки res://: 272 проверено, отсутствующих нет;
- динамические шаблоны ресурсов: 5 проверяются существующими тестами каталогов;
- целостность ZIP: успешно.

Runtime smoke-тест Godot 4.6.3 и Windows-экспорт выполняются GitHub Actions.
