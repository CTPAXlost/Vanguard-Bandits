Vanguard Bandits Remaster 1.9.10

Исправлена подтверждённая логами GitHub Actions причина зависания миссии VI.
Официальный Godot 4.6.3, запущенный с --headless, не обязан возвращать true для OS.has_feature("headless"). Из-за этого миссия VI входила в обычные диалоги и бесконечно ждала нажатия кнопки в CI.

Изменения:
- определение headless выполняется через DisplayServer.get_name();
- дополнительно учитываются VBR_SMOKE_MISSION, VBR_SMOKE_BRANCH и test_forced_branch;
- исправлены все такие проверки в миссиях V и VI, а не только место текущего падения;
- обе автоматические ветки миссии VI пропускают UI, применяют союз, снимают intro_pending и запускают ход;
- добавлен обязательный маркер MISSION6_BOOT_FINALIZED для обеих веток;
- GitHub Actions требует этот маркер до продолжения сборки;
- smoke-тесты, Godot import и Windows export остаются блокирующими; continue-on-error отсутствует.
