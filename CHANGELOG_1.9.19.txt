Vanguard Bandits Remaster 1.9.19
ИСПРАВЛЕНИЕ ЗАВИСАНИЯ RUNTIME-SMOKE И ЧЕСТНАЯ ПРОВЕРКА СЮЖЕТА

Причина падения 1.9.18 по свежему GitHub Actions:
- Godot, импорт, Python validation и компиляция всех 36 GDScript прошли.
- Миссии I–VI, движение, прогрессия ATAC и основная очистка погибших юнитов прошли.
- StorySmoke вызвал change_scene_to_file() прямо из _ready(). SceneTree ещё добавлял корневой узел, поэтому remove_child() был запрещён. После этого тест завис в интерактивной StoryChapter и был остановлен timeout через 240 секунд.

Исправления:
- StorySmoke больше не меняет активную сцену из _ready(). Он безопасно создаёт StoryChapter после одного кадра, проверяет обе сюжетные ветки, число диалогов, заголовок и непустую первую реплику, затем завершает тест.
- DeathCleanupSmoke больше не передаёт уже освобождённый объект в TypedArray.has(). Сравнение выполняется по сохранённому instance_id только для валидных объектов.
- MultiViewAtac не инвертирует вырожденный Basis во время удаления / масштабной анимации. Это устраняет поток ошибок det == 0 в Mission3Smoke.
- Ограничение каждого runtime-smoke уменьшено с 240 до 90 секунд: настоящий зависший тест будет обнаружен быстрее, но успешные тесты по-прежнему завершаются за секунды.
- Версия проекта и Windows-export: 1.9.19.

Важное:
- В свежем логе 1.9.18 уже подтверждены VALIDATION_OK, ALL_GDSCRIPT_COMPILE_OK count=36, ATAC_PROGRESSION_SMOKE_OK, загрузка миссий I–VI, Mission3/4/5/6, MovementInput и DeathCleanup.
- Windows-export в том запуске не начался, потому что job проверки остановился на зависшем StorySmoke.
