Vanguard Bandits Remaster 1.9.17
ИСПРАВЛЕНИЕ GITHUB ACTIONS И ПЕРЕНОСИМОГО ФАЙЛА БАЛАНСА

Причина сбоя 1.9.16:
- GitHub Actions остановился на Python validation.
- В репозитории отсутствовал файл с кириллическим именем:
  data/balance/Официальный_баланс_ATAC_по_уровням.txt
- Godot ещё не запускался: ошибка возникла до импорта, smoke-тестов и Windows-export.

Исправление:
- Добавлена каноническая ASCII-копия документа:
  data/balance/official_atac_balance_by_level.txt
- Валидатор теперь проверяет ASCII-файл, поэтому загрузка через Windows/GitHub не зависит от кодировки имени.
- Русская копия документа оставлена для удобства чтения.
- Версия проекта и Windows-export повышена до 1.9.17.
- GitHub artifact переименован в Vanguard-Bandits-Remaster-1.9.17-Windows.

Игровая логика, официальный баланс ATAC, уровни, опыт, прокачка, магия,
визуал старых ATAC и исправление направления движения из 1.9.16 сохранены.
