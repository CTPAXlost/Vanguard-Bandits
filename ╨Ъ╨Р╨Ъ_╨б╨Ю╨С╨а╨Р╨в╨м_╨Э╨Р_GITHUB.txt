КАК СОБРАТЬ VANGUARD BANDITS REMASTER 1.7 НА GITHUB

1. Откройте закрытый репозиторий проекта.
2. Полностью замените старые файлы содержимым архива.
3. Обязательно загрузите скрытую папку .github.
4. Откройте вкладку Actions.
5. Выберите Build Windows Remaster.
6. Нажмите Run workflow.
7. Дождитесь завершения статических тестов, импорта Godot, runtime smoke-тестов и экспорта.
8. Скачайте Artifact Vanguard-Bandits-Remaster-Windows-x64.

НОВЫЕ ОБЯЗАТЕЛЬНЫЕ ПРОВЕРКИ 1.7

- SKELETAL_ATAC_SMOKE_OK — все 14 типов ATAC создаются с Skeleton3D, полной геометрией и боевыми позами.
- DEATH_CLEANUP_SMOKE_OK — уничтоженный ATAC исчезает, освобождает клетку и удаляется из памяти.
- MOVEMENT_INPUT_SMOKE_OK — щелчок по зелёной клетке действительно перемещает юнит.

Если один из этих маркеров не появился, Windows-артефакт не создаётся, а журналы smoke-тестов загружаются отдельным артефактом.

Для автоматического релиза создайте тег v1.7.0. Workflow Release Windows Remaster соберёт Windows ZIP и приложит его к GitHub Release.

ПРОВЕРКА ПРОИЗВОДИТЕЛЬНОСТИ

- F10 показывает FPS, RAM, GPU и draw calls.
- F9 включает безопасный режим 30 FPS без теней.
- Журнал находится по пути:
  %APPDATA%\Godot\app_userdata\Vanguard Bandits Remaster\performance_v13.log

Важно: репозиторий должен оставаться закрытым.
