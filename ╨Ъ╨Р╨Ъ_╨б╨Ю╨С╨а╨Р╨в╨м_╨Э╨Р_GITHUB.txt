КАК СОБРАТЬ VANGUARD BANDITS REMASTER 1.5 НА GITHUB

1. Откройте закрытый репозиторий проекта.
2. Удалите старые файлы или загрузите новые с заменой.
3. Загрузите ВСЁ содержимое этой папки, включая скрытую папку .github.
4. Откройте вкладку Actions.
5. Выберите Build Windows Remaster.
6. Нажмите Run workflow.
7. Дождитесь завершения тестов, импорта Godot и экспорта.
8. Скачайте Artifact Vanguard-Bandits-Remaster-Windows-x64.

Для автоматического релиза создайте тег v1.5.0. Workflow Release Windows Remaster соберёт ZIP Windows x64 и приложит его к GitHub Release.

ПЕРВАЯ ПРОВЕРКА ОПТИМИЗАЦИИ

1. Запустите новую сборку, не смешивая её со старой папкой игры.
2. Через выбор миссий откройте миссию 4.
3. Нажмите F10 и играйте 10–15 минут.
4. Если начинается сильная нагрузка, нажмите F9 — включится режим 30 FPS без теней.
5. После выхода найдите файл:
   %APPDATA%\Godot\app_userdata\Vanguard Bandits Remaster\performance_v13.log
6. При повторении проблемы приложите журнал и снимок Диспетчера задач с колонками ЦП, Память, GPU и Ядро GPU.

Кинематографическая 3D-арена включена по умолчанию и работает для игрока, союзного ИИ и противников. При необходимости её можно отключить в лагере.

Важно: репозиторий должен оставаться закрытым, поскольку графика предназначена для личного фанатского проекта.
