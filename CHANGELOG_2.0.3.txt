VANGUARD BANDITS REMASTER 2.0.3 — ИСПРАВЛЕНИЕ КОМПИЛЯЦИИ GDSCRIPT

Причина сбоя 2.0.2:
- Миссия II в базовом `campaign_battle.gd` вызывала `_is_headless_or_smoke_runtime()`.
- Сам метод находился только в позднем наследнике `campaign_battle_v18.gd`.
- Из-за этого базовый скрипт не компилировался, а затем каскадно не разрешались v08, v12, v18, v19 и v20.

Исправлено:
- Метод перенесён в базовый `campaign_battle.gd`.
- Дубликат из `campaign_battle_v18.gd` удалён.
- Все миссии I–VII используют единый общий helper.
- `validate_project.py` теперь проверяет правильное расположение метода.
- Версия проекта, Windows export и артефакта обновлена до 2.0.3.

Свежий лог GitHub Actions дошёл до импорта и Python validation (`VALIDATION_OK`), после чего падал только на compile-smoke. После этого исправления нужен новый запуск GitHub Actions для подтверждения всех runtime-smoke и Windows-export.
