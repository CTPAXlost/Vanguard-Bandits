# Vanguard Bandits Remaster 2.0.4

Исправление зависания GitHub Actions на обычной загрузке миссии III.

- MissionBootSmoke больше не ждёт ручного проматывания сцен и выбора ветки в третьей миссии.
- Пропуск действует только для узкого CI boot-probe `VBR_SMOKE_MISSION=3` без заданной ветки.
- Обычная игра сохраняет все диалоги, дуэль на мосту и выбор Bastion.
- `Mission3Smoke` по-прежнему полностью проходит обе ветки и проверяет возможность движения после сюжетной сцены.
- Добавлена статическая защита от повторного появления блокировки.

Подробности: `CHANGELOG_2.0.4.txt`.
