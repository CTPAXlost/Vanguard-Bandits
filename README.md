# Vanguard Bandits Remaster 1.7.1

Закрытый фанатский прототип тактической RPG на Godot 4.6.3 для Windows.

## Главное в версии 1.7.1

Квадратные процедурные модели версии 1.7 заменены. Все 14 используемых в кампании ATAC теперь сохраняют собственный исходный внешний вид: фронтальный арт каждой машины разделён на прозрачные элементы брони и конечностей, а элементы закреплены на костях настоящего `Skeleton3D`. В нейтральной стойке они собираются обратно в исходный скин без изменения силуэта и цветов.

Поддерживаются Alba, Barbatos, Barazaph, Vedocorban, Cador, Solarus, Sarbelas, Einlager, Eigol, Amphisia, Haurol, Toreadore, Serata и Glaive. Для повторяющихся юнитов текстуры берутся из общего кэша, поэтому новая система не создаёт отдельные копии одного и того же изображения в памяти.

### Три полностью переработанные базовые атаки

- **Порез** — подготовка корпуса, широкий замах, рубящая дуга, вспышка контакта, искры и возврат в стойку.
- **Выпад** — перенос веса, быстрый шаг всем корпусом, колющий рывок, линейный след клинка и жёсткий импакт.
- **Длинный выпад** — усиленная подготовка, дальний рывок, длинный энергетический шлейф, мощная контактная вспышка и более тяжёлое восстановление.

Один и тот же обработчик используется для игрока, союзных ботов, противников и контратак. Отдельная 3D-арена не возвращалась: всё показывается непосредственно на тактическом поле.

### Переработанные яркие эффекты

По предоставленной раскадровке добавлены четырёхкадровые прозрачные последовательности:

- Яркая бомба;
- Вязкая буря в песках;
- Зыбучие пески;
- Буря в пустыне;
- Ледяной дождь;
- Шаровая молния.

Они сочетаются со светом, частицами, вспышками, тряской камеры и индивидуальными позами скелета. Остальные удары сохраняют собственные анимации пореза, выпада, длинного выпада, сильного пореза, броска копья, толчка плечом, ультразвука, скольжения и реакции на попадание.

### Исправлено уничтожение ATAC

При 0 HP машина:

- проигрывает падение;
- скрывает модель, HP и кольцо выбора;
- немедленно освобождает клетку;
- удаляется из списка боевых юнитов;
- окончательно освобождается через `queue_free()`.

Это устраняет ошибку, при которой уничтоженный ATAC оставался стоять на поле.

## Сохранённая оптимизация

- ограничение 60 FPS и VSync;
- low processor mode;
- пакетная MultiMesh-карта, вода и стены;
- общий кэш текстур, Mesh и материалов;
- короткоживущие VFX без постоянно активного SubViewport;
- F9 — безопасный режим 30 FPS без теней;
- F10 — FPS, RAM, GPU, draw calls и журнал `performance_v13.log`.

## Управление

- ЛКМ — выбрать ATAC, клетку или цель;
- стрелки — развернуть ATAC после перемещения;
- Enter — подтвердить выбранную цель;
- Esc — отменить выбор цели;
- «Отменить перемещение» — вернуть юнит на исходную клетку до совершения действия;
- WASD — камера;
- Q/E — вращение камеры;
- колесо — масштаб;
- F — фокус на выбранном юните;
- F9/F10 — производительность и диагностика.

## Сборка Windows через GitHub

1. Полностью замените содержимое закрытого репозитория файлами из архива.
2. Обязательно загрузите скрытую папку `.github`.
3. Откройте `Actions → Build Windows Remaster`.
4. Нажмите `Run workflow`.
5. После успешных тестов скачайте `Vanguard-Bandits-Remaster-Windows-x64`.

Workflow запускает 103 статических теста, импорт Godot 4.6.3, smoke-тесты исходных скинов на скелете, трёх базовых атак, основных миссий, клика перемещения и удаления уничтоженного ATAC, затем экспортирует Windows x64.

## Важно

В версии 1.7.1 используется исходный фронтальный арт каждого ATAC, сегментированный на подвижные слои. Это сохраняет узнаваемость и даёт скелетную артикуляцию без тяжёлых высокополигональных мешей. Система рассчитана на дальнейшую постепенную замену отдельных машин полноценными skinned-mesh моделями без изменения боевой логики.

Графика и персонажи предназначены для личного закрытого проекта. Репозиторий следует держать приватным.
