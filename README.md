# Vanguard Bandits Remaster 1.9.13

Исправление реальной runtime-ошибки миссии VI из `logs_82060482271.zip`.

Godot 4.6.3 успешно загрузил миссии I–V, обе стороны миссии VI и дошёл до проверки сохранения союза. Падение происходило в `CampaignState.complete_mission(6, branch)`: результат тернарного выражения был обычным `Array`, который присваивался переменной `Array[String]`.

В 1.9.13 списки персонажей и ATAC Южного и Северного королевств вынесены в типизированные константы, а разблокировка выполняется одной функцией без небезопасного присваивания массивов. Исправлены оба места: завершение миссии VI и восстановление прогресса после загрузки сохранения.

Перед Windows-export GitHub Actions по-прежнему обязательно выполняет Python-тесты, импорт Godot 4.6.3, компиляцию всех GDScript, миссии I–VI, обе стороны миссии VI, сохранение обоих союзов, runtime-smoke основных сцен и Windows-export. Ошибки не маскируются, `continue-on-error` отсутствует.
