# Vanguard Bandits Remaster 1.7

Закрытый фанатский прототип тактической RPG на Godot 4.6.3 для Windows.

## Главное в версии 1.7

Тактические ATAC больше не отображаются плоскими картинками. Все используемые в кампании машины создаются как объёмные процедурные роботы с `Skeleton3D`: корпус, голова, руки, кисти, ноги и ступни имеют отдельные кости, а броня прикреплена через `BoneAttachment3D`. Поэтому модель должна целиком оставаться видимой при вращении камеры и нормально участвовать в ходьбе и боевых позах.

Поддерживаются Alba, Barbatos, Barazaph, Vedocorban, Cador, Solarus, Sarbelas, Einlager, Eigol, Amphisia, Haurol, Toreadore, Serata и Glaive. Для них используются разные палитры, оружие, щиты и детали силуэта. Toreadore имеет отдельный четырёхногий корпус.

Отдельная 3D-арена отключена. Все удары игрока, союзного ИИ, противников и контратаки показываются на тактическом поле.

### Переработанные яркие эффекты

По предоставленной раскадровке добавлены четырёхкадровые прозрачные последовательности:

- Яркая бомба;
- Вязкая буря в песках;
- Зыбучие пески;
- Буря в пустыне;
- Ледяной дождь;
- Шаровая молния.

Они сочетаются со светом, частицами, вспышками, тряской камеры и индивидуальными позами скелета. Остальные удары сохраняют собственные анимации пореза, выпада, длинного выпада, сильного пореза, броска копья, толчка плечом, ультразвука, скольжения и реакции на попадание.

### Исправлено уничтожение ATAC

При 0 HP машина:

- проигрывает падение;
- скрывает модель, HP и кольцо выбора;
- немедленно освобождает клетку;
- удаляется из списка боевых юнитов;
- окончательно освобождается через `queue_free()`.

Это устраняет ошибку, при которой уничтоженный ATAC оставался стоять на поле.

## Сохранённая оптимизация

- ограничение 60 FPS и VSync;
- low processor mode;
- пакетная MultiMesh-карта, вода и стены;
- общий кэш текстур, Mesh и материалов;
- короткоживущие VFX без постоянно активного SubViewport;
- F9 — безопасный режим 30 FPS без теней;
- F10 — FPS, RAM, GPU, draw calls и журнал `performance_v13.log`.

## Управление

- ЛКМ — выбрать ATAC, клетку или цель;
- стрелки — развернуть ATAC после перемещения;
- Enter — подтвердить выбранную цель;
- Esc — отменить выбор цели;
- «Отменить перемещение» — вернуть юнит на исходную клетку до совершения действия;
- WASD — камера;
- Q/E — вращение камеры;
- колесо — масштаб;
- F — фокус на выбранном юните;
- F9/F10 — производительность и диагностика.

## Сборка Windows через GitHub

1. Полностью замените содержимое закрытого репозитория файлами из архива.
2. Обязательно загрузите скрытую папку `.github`.
3. Откройте `Actions → Build Windows Remaster`.
4. Нажмите `Run workflow`.
5. После успешных тестов скачайте `Vanguard-Bandits-Remaster-Windows-x64`.

Workflow запускает 99 статических тестов, импорт Godot 4.6.3, smoke-тесты основных миссий, всех 14 скелетных моделей, клика перемещения и удаления уничтоженного ATAC, затем экспортирует Windows x64.

## Важно

Новые роботы являются процедурными игровыми моделями на общем скелетном стандарте, а не готовыми вручную вылепленными AAA-мешами. Это рабочая замена неисправных плоских ATAC: она обеспечивает целую геометрию, риг и анимацию. В следующих версиях геометрию каждого типа можно постепенно детализировать без замены боевой и скелетной системы.

Графика и персонажи предназначены для личного закрытого проекта. Репозиторий следует держать приватным.
