# Vanguard Bandits Remaster 1.9.6

Закрытый фанатский прототип тактической RPG на Godot 4.6.3 для Windows.

## Главное в версии 1.9.6

### Глава V

- проходы замка полностью открыты: без створок, столбов, перемычек и скрытых блоков;
- Sadira, Franco и Halak находятся на открытом поле и доступны для атаки обеим сторонам;
- магазин показывает весь общий каталог оружия, амулетов и камней вместе с изображениями;
- новые и прежние ATAC используют скелетный рендер с исходными сегментированными скинами;
- сохранены подкрепление Zakov, Sharking, атаки Faulkner и остальные механики защиты замка.

### Новая глава VI — «Война Севера и Юга»

Глава открывается в ветке, где Kamorge погиб. После освобождения Bastion и Andrew отряд Zeira ведёт их через лес к Южному королевству. На границе герои видят сражение двух королевств и выбирают сторону.

**Южное королевство:**

- Logan / Crimson, уровень 25;
- Claire / Rahabor, уровень 15;
- Shion / Rahabor, уровень 22;
- шесть Nordilian / Rahabor уровней 10–15;
- ещё шесть Rahabor прибывают после уничтожения первой группы.

**Северное королевство:**

- Alden / Altagrave, уровень 24;
- Devlin / Snow Soldier, уровень 19;
- Barlow / Ratatosk, уровень 14;
- шесть Matisse / Ratatosk уровней 10–15.

Выбранное королевство становится союзником, а отвергнутая сторона атакует и героев, и выбранную армию. Решение сохраняется для дальнейшего сюжета.

### Новые механики

- Logan получает два действия каждый ход, отражение атак и два применения усиления урона на 100%;
- Alden невосприимчив к магии, может ответить айсбергом и восстанавливает союзникам 50 HP и 30 энергии каждый раунд;
- Devlin один раз создаёт клона с 60% характеристик;
- добавлены «Злое сердце», «Мороз», «Вихрь бури», выстрелы, ракетница, ледяные удары и неотражаемое комбо;
- Crimson, Rahabor, Altagrave, Snow Soldier и Ratatosk подключены к скелетному отображению и полевым анимациям.

## Управление

- ЛКМ — выбрать ATAC, клетку или цель;
- стрелки — выбрать направление после перемещения;
- Enter — подтвердить цель;
- Esc — отменить выбор;
- «Отменить перемещение» — вернуть юнит до выполнения действия;
- WASD — камера;
- Q/E — вращение;
- колесо — масштаб;
- F — фокус на выбранном ATAC;
- F9 — безопасный режим 30 FPS;
- F10 — диагностика производительности.

## Сборка Windows через GitHub

1. Полностью замените содержимое закрытого репозитория файлами из архива.
2. Обязательно загрузите скрытую папку `.github`.
3. Откройте `Actions → Build Windows Remaster`.
4. Нажмите `Run workflow`.
5. После успешных проверок скачайте артефакт `Vanguard-Bandits-Remaster-Windows-x64`.

GitHub Actions импортирует проект в Godot, запускает runtime-проверки прежних миссий и обеих сторон главы VI, затем экспортирует Windows x64. Если новая глава или одна из её армий не создаётся, экспорт останавливается и прикладывает диагностический лог.
