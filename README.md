# Vanguard Bandits Remaster 1.9.14

Тактическая сюжетная сборка для **Godot 4.6.3**.

Главное обновление — реально подключённая глава VI «Война Севера и Юга» для ветки, где Kamorge погиб. Восстановлены сюжетные диалоги, добавлен выбор будущего союзника, подключены новые персонажи и цельные изображения ATAC, исправлены открытые проходы замка и каталог общего магазина.

## Проверка перед Windows-export

GitHub Actions обязательно выполняет:

1. все Python-регрессионные тесты;
2. импорт проекта Godot 4.6.3;
3. компиляцию каждого GDScript;
4. обычную загрузку миссий I–VI и обеих сторон главы VI;
5. runtime-smoke боевой сцены, движения, лагеря, выбора миссий, замка, магазина, ATAC и сохранения союза;
6. Windows x64 export.

Ошибки не маскируются. `continue-on-error` отсутствует.
