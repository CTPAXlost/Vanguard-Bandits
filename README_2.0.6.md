# Vanguard Bandits Remaster 2.0.6

Версия 2.0.6 переводит тактические ATAC на цельные full-body спрайты (силуэт PS1),
выравнивает их рост на карте и усиливает 2D-анимации ударов/магии с яркими эффектами
без отдельного 3D-боя.

Основное:
- все тактические ATAC через MultiViewAtac;
- общая нормализация высоты по контуру спрайта;
- CombatFx: ленты ударов, выпады, вспышки, магические сферы;
- CinematicVfx с procedural fallback, если нет storyboard-кадров.

Подробности: `CHANGELOG_2.0.6.txt`.
