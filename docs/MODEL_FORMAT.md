# Формат моделей ATAC — текущие результаты

## Подтверждённая раскладка EPICA

Для ATAC с ID `N` первая подтверждённая пара ресурсов вычисляется так:

- TIM-текстура: блок `266 + N × 2`;
- модель: следующий блок.

Проверенные пары:

| ATAC | ID | TIM | Модель |
|---|---:|---:|---:|
| Alba | 3 | 272 | 273 |
| Serata | 4 | 274 | 275 |
| Glaive | 6 | 278 | 279 |

## Контейнер модели

Внутри модельного блока:

- по смещению `0x10` находится стандартный заголовок PlayStation TMD (`0x41`);
- TMD содержит общую таблицу вершин и отдельные группы примитивов для деталей корпуса;
- после геометрии находится собственная иерархия Vanguard Bandits: родители деталей, смещения шарниров и данные поз/анимаций;
- модельные TIM используют 16-цветные CLUT-палитры, хотя поле режима не соответствует обычной трактовке стандартного TIM;
- последний и последующие объекты являются сменным оружием/эффектами и пока экспортируются как список вложений, а не приклеиваются к корпусу.

## Что экспортируется сейчас

`tools/vb_model_export.py` создаёт для Alba, Serata и Glaive:

- статическую нейтральную модель OBJ/MTL;
- использованные палитры PNG;
- `model.json` с иерархией, исходными блоками и техническими параметрами;
- `models.json` с результатами импорта.
