# ATAC — статус реконструкции

Оригинальные TMD-полигоны и TIM-палитры извлечены. Проблемой остаётся точная интерпретация костных матриц и кадров анимации, из-за чего предыдущая статическая сборка распадалась на отдельные детали.

Версия 0.3 добавляет цельный каркас ремастера:

- полный корпус;
- руки, ноги, голова и ранец;
- оружие на отдельном `WeaponPivot`;
- узнаваемые цветовые схемы Alba, Serata и Glaive;
- возможность анимировать оружие и весь корпус без разрушения силуэта.

Дальше оригинальные бронепластины будут переноситься на этот каркас по одной группе после подтверждения их локальных трансформаций.
