# First mission status — 0.5

Mission 1 is a visual tactical reconstruction used to validate gameplay systems.

Implemented:
- Bastion / Alba, level 1, 180 HP, movement 6;
- two Barbatos soldiers, 90 HP, movement 5;
- one Barbatos commander, 110 HP, movement 5;
- movement animation and reachable-cell highlight;
- fatigue, Slash, Lunge, Long Lunge, Defence, Dodge and Reflect Attack;
- back-attack defence bypass;
- direct combat effects on the tactical map (no separate 3D battle transition).

Not final yet:
- exact original map geometry and mission script extraction;
- final authored high-poly ATAC models and skeletal animation;
- magic and special ATAC abilities beyond Alba reflection.
