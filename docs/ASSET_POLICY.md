# Asset policy

This repository must remain private while it contains any locally extracted game reference data or user-supplied reference artwork.

- Original intro movies and original soundtrack are excluded.
- `project/assets/imported/` contains technical local reference exports used during reverse engineering.
- `docs/references/remaster_models/` contains user-supplied turnaround/reference artwork.
- `project/assets/ui/portraits/` contains the two portraits currently displayed by the prototype.
- Public releases should contain only code and newly created assets that the project owner has permission to distribute.
