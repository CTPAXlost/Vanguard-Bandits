# Подтверждённые форматы

## Образ

Поддерживаемая версия: `SLUS-01070`.

Файлы корня диска:

- `EPICA.BIN` — 44 267 520 байт;
- `SLUS_010.70` — 380 928 байт;
- `STELLA.XA` — потоковые материалы, в ремастер не импортируются;
- `SYSTEM.CNF`.

Поддерживаемые сектора:

- ISO 2048;
- MDF 2448, пользовательские данные с позиции 24;
- RAW 2352, пользовательские данные с позиции 24.

## EPICA.BIN

В начале находится таблица записей по 8 байт:

```text
offset: uint32 little-endian
size:   uint32 little-endian
```

Таблица заканчивается записью с нулевым размером. В исследуемом образе найдено 703 блока.

## Ресурсы

- `0x00000010` в начале — стандартный PS1 TIM;
- `0x00000041` в начале — вероятный PS1 TMD;
- известные маркеры сценариев/данных: `MFONT`, `SPSB`, `SPDB_0`, `SPDB_1`, `LOADBUF`.

Каталоги ATAC и персонажей в `project/data/catalogs` пока являются картой известных ID. Их связь с конкретными блоками EPICA будет фиксироваться в следующих версиях.
