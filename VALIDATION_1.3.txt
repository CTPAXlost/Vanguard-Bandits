ОЦЕНКА ПАМЯТИ ТЕКСТУР МИССИИ 4

До исправления четыре ракурса загружались отдельно для каждого повторяющегося юнита. Только для основных типов ATAC четвёртой миссии это могло занимать около 286,8 МиБ распакованных RGBA-текстур.

После исправления:
- при загрузке всех четырёх ракурсов каждого уникального типа: около 107,7 МиБ;
- сразу после появления юнитов, когда нужен только начальный ракурс: около 26,9 МиБ.

Это оценка только изображений ATAC без учёта движка, интерфейса, карт, буферов и драйвера GPU.

ОГРАНИЧЕНИЕ ПРОВЕРКИ

В текущей локальной среде нет исполняемого Godot 4.6.3, а сетевой доступ для его загрузки недоступен. Поэтому локальный импорт проекта, запуск GDScript внутри движка и экспорт EXE здесь не выполнялись.

После загрузки архива в GitHub workflow автоматически:
- скачает официальный Godot 4.6.3;
- импортирует проект;
- запустит smoke-тесты основных сцен;
- экспортирует Windows x64;
- при ошибке приложит журналы smoke-тестов.
