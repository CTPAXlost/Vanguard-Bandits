# Vanguard Bandits Remaster 2.0.5

Версия 2.0.5 исправляет общий класс зависаний автоматической загрузки миссий на интерактивных диалогах и заменяет последовательную остановку CI на полную матрицу проверок.

Основное:
- единый boot-probe guard для диалогов всех миссий;
- исправленная нормальная загрузка миссии IV;
- полный Mission4Smoke с проверкой Eigol, уровней, опыта и перемещения;
- проверка всех 9 вариантов загрузки миссий даже при нескольких ошибках;
- запуск всех 13 runtime-smoke с итоговым полным списком сбоев;
- строгий workflow без `continue-on-error`;
- Windows x64 export только после зелёной полной матрицы.

Подробности находятся в `CHANGELOG_2.0.5.txt`.
