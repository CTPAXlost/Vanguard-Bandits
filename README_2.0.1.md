# Vanguard Bandits Remaster 2.0.1

Godot 4.6.3. Репозиторий содержит исходный проект, игровые ресурсы, семь сюжетных миссий, официальную прогрессию ATAC, runtime-smoke и Windows export workflow.

## Основное в 2.0.1

- оптимизированы долгие боевые сессии и очистка временных эффектов;
- Solarus и Sarbelas заменены цельными качественными turnaround-моделями;
- исправлены опыт, рост уровня, HP и 3 очка прокачки непосредственно в бою;
- тестовые герои и союзники масштабируются под уровень миссии, оставаясь немного слабее противника;
- поворот перед завершением хода выполняется стрелками клавиатуры;
- замковые ворота видимы, полностью открыты и не блокируют проход;
- добавлены новые storyboard-VFX для Crimson, Snow Soldier и Altagrave.

Полный перечень находится в `CHANGELOG_2.0.1.txt`.

## GitHub Actions

Workflow `.github/workflows/godot-ci.yml` использует Godot 4.6.3, кеш редактора, импортированных ресурсов и Windows export templates. Проверки блокирующие; `continue-on-error` не применяется.
