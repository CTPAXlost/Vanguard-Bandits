ИСПРАВЛЕНА ОШИБКА ИЗ GITHUB ACTIONS

Лог сборки показал точную причину остановки:
SCRIPT ERROR: Out of bounds get index '2' (on base: 'Array')
at: _create_house (res://scripts/battle_prototype.gd:350)

В миссии II дома записаны в старом формате:
size: [ширина, глубина]
height: отдельное значение

Код версии 1.9.5 ожидал новый формат из трёх элементов:
size: [ширина, высота, глубина]

В версии 1.9.6 загрузчик домов поддерживает оба формата и имеет безопасные значения по умолчанию для неполных данных. Обязательный smoke-тест миссий I–VI не отключён, continue-on-error не добавлен.


ДОПОЛНИТЕЛЬНО ИСПРАВЛЕН КОНТУР ТЕСТОВ

Четыре тестовых файла содержали 21 top-level test_* функцию, которую unittest discover раньше молча не запускал. В них добавлена регистрация через load_tests(). Теперь команда GitHub Actions действительно выполняет 164 теста. Все 164 теста локально прошли успешно.
