Vanguard Bandits Remaster 1.4 — проверка пакета

Выполнено локально:
- полный Python unittest-набор проекта: 74 теста;
- проверка существования и прозрачности новых иконок магазина;
- проверка раздельных контекстов tactical/arena;
- проверка ограничения диалога первой миссией;
- проверка флага, исключающего повторный спавн Kamorge;
- проверка путевого выбора целей и повторной оценки после движения союзного ИИ;
- проверка сохранения настройки арены и версии save 14;
- проверка YAML workflow;
- проверка структуры файлов и ссылок ресурсов.

Runtime-проверка Godot:
- в GitHub Actions добавлена сцена ArenaSmoke.tscn;
- она создаёт Serata и Barbatos, проигрывает «Сильный порез» на арене и требует маркер ARENA_SMOKE_OK;
- BattlePrototype, Mission 3, Mission 4, магазин, лагерь и сюжетные сцены также проходят существующие smoke-тесты перед экспортом Windows.

Ограничение среды:
- локального исполняемого Godot 4.6.3 в контейнере нет, поэтому фактический runtime-smoke и Windows-экспорт выполняет GitHub Actions после загрузки архива.
