Vanguard Bandits Remaster 1.6.2 — отчёт проверки

Результат локальной проверки:
- 91 Python/unit-тест: OK.
- Исправленный обработчик ввода передаёт обычные события в родительский BattlePrototype.
- Мышь в режиме выбора цели также передаётся в общий _handle_click().
- Добавлены MovementInputSmoke.tscn и movement_input_smoke.gd.
- GitHub Actions требует маркер MOVEMENT_INPUT_SMOKE_OK перед экспортом Windows.
- Структура архива и скрытая папка .github сохранены.

Причина ошибки 1.6/1.6.1:
campaign_battle_v08.gd переопределил _unhandled_input(), но не вызвал
super._unhandled_input(event). Поэтому базовый код не получал левый щелчок
по зелёной клетке и _move_player_to() не запускался.

Ограничение локальной среды:
исполняемый Godot 4.6.3 локально отсутствует, поэтому новый runtime smoke-тест
будет фактически выполнен GitHub Actions до сборки Windows. При отсутствии
маркера MOVEMENT_INPUT_SMOKE_OK workflow завершится ошибкой и не выпустит EXE.
